# Tools

Esta pasta é reservada a ferramentas de build, release, preflight, empacotamento e validação do Technolife Data Studio.

Regras:

- ferramentas daqui não fazem parte automaticamente do pacote instalado no cliente;
- não armazenar secrets;
- scripts de release devem ser reproduzíveis;
- qualquer ferramenta que altere uma Instance deve ter escopo e documentação claros.

Os scripts operacionais serão adicionados nas tarefas correspondentes.
